# Antigravity Persian RTL & BiDi Output Formatter (`persian-rtl`)

افزونه (Plugin) اختصاصی برای **Google Antigravity** جهت راست‌چین‌سازی استاندارد (`RTL`) و جلوگیری از به‌هم‌ریختگی ترتیب کلمات در جملات ترکیبی **فارسی و انگلیسی (BiDi)**.

---

## مشکل جملات ترکیبی فارسی و انگلیسی چیست؟

وقتی در خروجی‌های ایجنت، جملات فارسی با اصطلاحات فنی انگلیسی، نام فایل‌ها، اعداد و علائم نگارشی (`:`، `-`، `()`، `/`) ترکیب می‌شوند، الگوریتم دوجهته یونیکد (Unicode Bidirectional Algorithm) در بسیاری از رندررهای Markdown دچار خطا می‌شود:
1. قرار گرفتن دو کلمه انگلیسی در نزدیکی هم با علائم خنثی باعث می‌شود کل عبارت بین آن‌ها چپ‌به‌راست (LTR) رندر شود و ترتیب کلمات فارسی و انگلیسی جابه‌جا شود.
2. شروع شدن یک آیتم لیست با کلمه انگلیسی باعث چپ‌چین شدن کل خط می‌شود.
3. پرانتزها و دونقطه‌ها (`:`) در انتهای کلمات انگلیسی به سمت نادرست می‌پرند.

---

## این افزونه چه کاری انجام می‌دهد؟

1. **قوانین همیشه‌فعال (`rules/AGENTS.md`):**
   * ایجنت را موظف می‌کند تمام بخش‌های توضیحی فارسی را درون بلوک‌های `<div dir="rtl" align="right">` قرار دهد تا جهت پایه پاراگراف همیشه راست‌به‌چپ باشد.
   * بلوک‌های کد (` ``` `) را خارج از تگ `rtl` نگه می‌دارد تا کدها کاملاً چپ‌به‌راست باقی بمانند.
   * تمام کلمات و شناسه‌های فنی انگلیسی داخل متن فارسی را درون Backtick (`` `...` ``) یا تگ `<bdi dir="ltr">` ایزوله می‌کند و با کاراکترهای کنترل جهت (`&rlm;`) از به‌هم‌ریختگی ترتیب جملات جلوگیری می‌کند.
2. **مهارت و اسکریپت اصلاح خودکار (`skills/persian-rtl-formatter`):**
   * شامل راهنمای کامل BiDi و اسکریپت پایتون `scripts/fix_bidi.py` برای اصلاح خودکار فایل‌های Markdown موجود که دچار به‌هم‌ریختگی متون فارسی و انگلیسی شده‌اند.

## ساختار مخزن

```text
antigravity-persian-rtl/
├── plugin.json                                     # مانیفست افزونه Antigravity
├── README.md                                       # مستندات افزونه
├── assets/
│   └── logo.svg                                    # آیکون افزونه
├── rules/
│   └── AGENTS.md                                   # قوانین همیشه‌فعال BiDi و RTL برای ایجنت
└── skills/
    └── persian-rtl-formatter/
        ├── SKILL.md                                # مهارت فرمت‌دهی و اصلاح متون دوزبانه
        └── scripts/
            └── fix_bidi.py                         # اسکریپت پایتون اصلاح خودکار فایل‌های Markdown
```

## نحوه نصب در Antigravity

برای نصب این افزونه در مسیر تنظیمات سراسری Antigravity (`~/.gemini/config/plugins/persian-rtl`):

```bash
mkdir -p ~/.gemini/config/plugins
cp -r /home/master/PJ/git-projects/Omni/Childs/antigravity-persian-rtl ~/.gemini/config/plugins/persian-rtl
```
